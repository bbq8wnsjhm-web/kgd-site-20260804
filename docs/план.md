# План работ

## Проблемы сайта

- Главная страница тяжелая: `main-bg.mp4` весит 82,4 МБ, музыка - 8,65 МБ. Для фонового видео это много.
- Музыка грузится через `preload="auto"`, даже когда браузер блокирует автозапуск.
- Папка проекта весит примерно 900 МБ. Внутри лежат лишние тяжелые файлы:
  - `main-bg.mov` на 307 МБ;
  - архив `моушнсайт` на 268 МБ;
  - `.git` на 189 МБ;
  - временный профиль Chrome;
  - временные PNG.
- GSAP не загрузился в локальной проверке. Сайт не ломается, но полноценные анимации могут пропасть при проблемах с CDN.
- На главной странице нет `h1`: название клуба оформлено как `div`, а единственный заголовок там `h2`. Это плохо для SEO и доступности.
- `sessionStorage` записывается на каждое событие `timeupdate` аудио, то есть несколько раз в секунду.
- В `README.md` остались старые пути `C:\Users\ASUS\Desktop\сайт`.
- В `.gitignore` не исключены временный профиль и временные PNG.

## Что было нормальным

- JavaScript синтаксически корректен.
- Локальные ссылки и ресурсы не битые.
- Все четыре страницы открываются без ошибок в консоли.
- Кнопки работают.
- На мобильной ширине нет горизонтального скролла.

## Приоритет исправлений

1. Сжать видео и музыку.
2. Вынести архивы из проекта.
3. Локализовать GSAP или усилить запасной вариант.
4. Добавить `h1` на главную страницу.
